## 金句

**1. Where there is a will, there is a way.**

- 释义：有志者事竟成。
- 例句：As the saying goes, where there is a will there is a way, and persistence always pays off.
- 译文：常言道，有志者事竟成，坚持终会有回报。
- 用法：①英语谚语；②个人品质——论证毅力与坚持，置于第二段例证引入处。

**2. Rome was not built in a day.**

- 释义：罗马不是一天建成的。
- 例句：Rome was not built in a day, so lasting progress in language learning calls for patience.
- 译文：罗马不是一天建成的，因此语言学习上的持久进步需要耐心。
- 用法：①英语谚语；②学习与教育——论证循序渐进，用于分析段收束。

**3. Constant dripping wears away a stone.**

- 释义：水滴石穿。

- 译文：水滴石穿；每天读几页书终会有回报。
- 用法：①英语谚语；②个人品质——强调日积月累的效应，宜置于第二段论证。

- 用法：①Thomas Edison；②个人品质——论证勤奋胜过天资，用于第二段论证。

- 用法：①英语谚语；②学习与教育——论证规划的重要性，宜用于建议段。

**8. Strike while the iron is hot.**

**9. Knowledge is power.**
