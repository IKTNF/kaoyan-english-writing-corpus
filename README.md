# 考研英语一 · 作文语料库

面向**考研英语（一）作文**（大作文 160–200 词图画/图表作文 + 小作文 100 词应用文）的分类语料库。

- **870 条**主题语料（**821 个不重复表达**），按 **17 个板块**分类
- **16 类**小作文整篇填空模板（117 块骨架 · 1541 词）
- **真题索引**：大作文 1998–2025 共 28 套 / 小作文 2005–2025 共 21 套，含考据过的**原题**与 **49 篇原创范文**、116 个参考文献出处
- 可搜索、可隐藏中文背诵、可标记掌握进度

> 定位：只收**中高级、有区分度、阅卷老师会给分**的表达。good / bad / many / important / think / people 这类初级词一律不收，只在「高级替换词表」里作为被替换对象出现。

## 怎么用

**双击 `index.html`** 即可。纯单文件、零依赖、离线可用，不需要联网、不需要装任何东西。

| 想干什么 | 怎么做 |
|---|---|
| 换板块 | 点左侧任意板块（17 个语料板块 + 2 个真题索引 + 快速视图） |
| 看真题原题 / 范文 | 侧栏「真题（原题 + 范文）」下的**大作文真题索引** / **小作文真题索引** |
| 背小作文整篇模板 | 侧栏「小作文·应用文语料」最上方的 **🧩 小作文题型模板库** |
| 找某个词 | 顶部搜索框，或按 `/` 聚焦；Esc 清空 |
| 背单词 | 点 `👁 背诵模式`（或按 `R`）隐藏全部中文，点卡片逐条揭示 |
| 标记背会了 | 点卡片上的 `✓`，左侧进度条和底部百分比实时更新 |
| 收藏重点 | 点 `★`，再用 `★ 收藏` 按钮只看收藏 |
| 只背没背会的 | 点 `✓ 未掌握`，已掌握的自动隐藏 |
| 打乱顺序抽查 | 点 `🔀 乱序` |
| 跟读发音 | 点卡片上的 `🔊`（用系统英文语音） |
| 导出/打印 | `⬇ 导出` 存成 Markdown；`🖨 打印` 直接出纸质版 |
| 字号 / 夜间 | `A−` `A+` / `🌙` |

进度保存在浏览器 localStorage，关掉再打开还在。

### 🧩 小作文题型模板库

和上面 4 个句库**互补**——那边背**句子**，这边背**整篇骨架**。

16 类应用文，每类给一套「称呼 → 首段 → 主体 2—3 块 → 结尾 → 落款」的完整填空模板（`___` 处自行替换），填完约 100 词。骨架合计 1541 词。

| 题型 | 星级 | 真题年份 | 题型 | 星级 | 真题年份 |
|---|---|---|---|---|---|
| 建议信 | ★★★★★ | 2007/2009/2012/2014/2021/2024 | 辞职信 | ★★★ | 2005 |
| 通知 | ★★★★★ | 2010/2016/2020/2023 | 感谢信 | ★★ | 备用 |
| 答复/回信 | ★★★★★ | 2019/2024/2025 | 咨询信 | ★★ | 备用 |
| 推荐信 | ★★★★ | 2011/2015/2017 | 求职信 | ★★ | 备用 |
| 邀请信 | ★★★★ | 2013/2018/2022 | 投诉信 | ★★ | 备用 |
| 道歉信 | ★★★ | 2008 | 祝贺信 | ★★ | 备用 |
| 申请信 | ★★★ | 2006 | 告示/招募 · 备忘录 · 便条/留言 | ★★ | 备用 |

每个题型卡片包含四部分：

1. **整篇填空骨架** — 分块标注，英文是可直接背下来填空的整句，每块配中文与写法提示（如"称呼后用逗号""recommend that 后接虚拟语气用原形"）
2. **备用句** — 3 组（首段 / 主体句式 / 结尾），每组 3—4 条，考场可直接换用
3. **易错点** — 每类 5 条，都是具体失分点（如"只道歉不给补救方案""通知写成 Dear Sir 即失分""备忘录写成书信体直接判文体不符"）
4. **真题套用** — 该类考过的年份逐条说明当年题目要点

点击卡片右上角 `复制骨架` 可把整篇英文模板复制到剪贴板；按 `R` 进背诵模式会模糊中文与提示。

> 星级已做诚实处理：**没有真题背书的题型统一封顶 ★★**，避免排序误导复习优先级。



侧栏「真题」下有两个互相独立的索引，每套都同时给出**原题**和**原创范文**：

| 索引 | 范围 | 套数 | 内容 |
|---|---|---|---|
| 🗂 大作文真题索引 | 1998–2025 | 28 | 原题 Directions、画面/图表描述、图上文字、写作要求、可复用角度 + 原创范文 |
| ✉️ 小作文真题索引 | 2005–2025 | 21 | 原题 Directions 英文原文、题型、收信人/受众、写作要点 + 原创范文 |

- **原题**：逐条给出该年的 Directions 与画面内容（含图上文字），并给出**考据来源与置信度**，中/低置信度的会显式标注提醒核对。历年真题里流传着不少错题面（例如某些汇总页把 2011 年的题面复制到了 2012 年、把 2022 年写成了 2013 年的题），本索引逐条交叉验证后做了订正。
- **范文**：**本书原创**，非官方答案。大作文平均 191 词、小作文平均 117 词；每篇配中文译文与「结构」提纲（说明每段写什么、用什么句式）。
- **参考范文出处**：每套卡片底部给出该年**真题解析页链接**（学信网·研招网 / 新东方 / 中公 / 启航等），想对照市面上现成的范文可以从这里去查。共 116 个链接，**全部实测可访问**（`node src/check-links.mjs` 可复验）。
  > 只做**链接**、不收录正文：市面范文多为机构与作者的版权作品，整篇复制进公开仓库会有下架风险。
- 每套卡片右侧的板块链接可**点击直接跳到对应语料**；搜索框在索引视图里会同时检索题面与范文正文。
- 顶部按钮：`展开全部范文` / `全部收起` / `只看原题`；背诵模式下范文中译文会被模糊，点一下揭示。
- 大作文索引末尾附四条命题规律（话题族分布、题型分布、分值演变、首段写法）。

> 题面考据说明：1998/2000/2005/2006/2008/2017/2020/2021/2023/2024 十个年份的原有题面表述经过核查后被订正（例如 **2000 年实为图画而非图表**、**2024 年是「漫画 + 柱状图表」组合题**）。标为 `medium` 的年份（2013、2023）请以官方真题原文为准。

## 自己改语料 / 重新构建

每条语料的字段：

```json
{
  "en": "perseverance",
  "basic": "（仅高级替换词表需要）被替换的初级词",
  "zh": "坚持不懈；百折不挠",
  "pos": "n.",
  "type": "word | phrase | pattern | proverb",
  "example": "练到能直接搬进作文的完整英文例句",
  "exampleZh": "例句中文翻译",
  "note": "搭配 / 用在哪一段 / 易错点"
}
```

改完 `data/` 里的 json 后运行：

```powershell
cd C:\Users\Administrator\Desktop\考研英语一作文语料库
node src/build.mjs      # 校验并重新生成 index.html 与 markdown/
node src/audit.mjs      # 可选：查初级词泄漏、重复、乱码
node src/verify.mjs     # 可选：无头浏览器跑一遍交互自检
```

`build.mjs` 会**先校验再输出**：字段缺失、`type` 非法、板块内重复都会报错并终止，不会产出坏页面。

### 改动真题索引

真题索引由 `data/00-index.json` 的 `partA`（小作文）/ `partB`（大作文）两块组成，每套含 `directionsEn` / `pictureZh` / `sections` / `tip` / `model` 等字段。

- 只加/改**范文**：直接编辑 `00-index.json` 里某年的 `model`（`en` 用 `\n\n` 分段），然后跑 `node src/build.mjs`。
- 要**整体重跑考据流水线**：

```powershell
node src/migrate-index.mjs   # 考据结果 + 主题归类 → 00-index.json（幂等，从 00-index.old.json 读主题归类）
node src/merge-models.mjs    # data/_research/models-*.json → 各年 model 字段（顺带校验词数区间）
node src/build.mjs
```

`merge-models.mjs` 会检查词数（大作文 150–220、小作文 85–130）、缺失年份、重复年份与空字段，不合格直接报错不写盘。

### 改动小作文模板库

编辑 `data/18-templates.json` 的 `templates[]`，每个模板含 `type / typeEn / stars / freq / scene / wordTarget / blocks[] / alternatives[] / pitfalls[] / realExams[]`。
从分片重建（分片在 `data/_research/templates-T*.json`）：

```powershell
node src/merge-templates.mjs   # 校验并合并 → 18-templates.json（无真题的题型星级自动封顶 ★★）
node src/build.mjs
```

`data/_research/` 是考据中间产物（抓取的网页原文、范文与模板分片），已在 `.gitignore` 中排除。

> ⚠️ 在 PowerShell 里跑 node 脚本时**不要**用 `... | Select-Object -First N` 截断输出——
> PowerShell 会提前终止上游进程，脚本可能还没写盘就被杀掉。先把输出存进变量再切。

## 一个细节

同一表达可能出现在两个板块（如 `integrity` 同时在「个人品质」和「社会公德」，两边例句不同）。
这类卡片带 `＋1 板块` 标签，且**掌握/收藏状态按「表达」全局共享**——在一个板块点过 `✓`，另一个板块里也自动算已掌握，不会重复劳动。
